# MITS Placement Management Portal

A web-based Student Placement Management Portal developed for MITS College.


live website : mits-placement-portal.vercel.app

## Features

### Student
- Student registration and login
- View eligible companies
- View company eligibility criteria
- Apply for placement drives
- Upload resume and certificates
- Add project links and technical skills
- Track application status

### Placement Officer
- Add companies
- Update company details
- Delete companies
- Create placement drives
- View student applicants
- Update selection status

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Node.js
- Express.js
- MySQL
- Git & GitHub
